# 롤 10분 승률 줄다리기

**10분 스냅샷 한 장으로 승패가 선형으로 결정되는가** — 이 질문을 검증하고,
그 답(회귀계수)을 **그대로 게임 규칙으로 바꿔** 사람이 직접 쳐보게 만든 프로젝트.

다이아~마스터 **9,879경기**로 학습한 승률 모델 + 채팅으로 진행하는 **60초 1대1 대결**.
두 기기가 같은 방에서 동시에 플레이한다(휴대폰 가능).

---

## 왜 게임인가 — 게임은 주제가 아니라 검증 장치다

계수를 표로 읽으면 납득되지 않는다. 특히 **골드를 통제하면 타워·킬·CS 계수가 음수로 뒤집히는데**,
글로는 "버그 아니냐"로 끝난다. 그래서 계수를 **쿨타임·보상·상한으로 환산해 직접 치게** 했다.
**계수가 틀렸다면 게임 밸런스가 깨진다** — 반증 가능한 형태로 모델을 노출한 것이다.

## 결론 4줄

1. **데이터는 선형이다.** 23개 아키텍처 중 상위권은 전부 선형. 같은 XGBoost에서 부스터만
   트리로 바꾸면 AUC 0.8109 → 0.7612. 비선형을 더할수록 나빠진다.
2. **성능 한계는 모델이 아니라 데이터다.** 학습곡선은 2,200표본부터 평평하고(과적합 격차 0.0008),
   피처 12종 추가가 전부 CV 표준편차의 1/44 안이다.
3. **AUC로는 모델이 안 골라진다**(차이 0.002~0.05). 게임에 필요한 건 **단조성·외삽·재현성**이고,
   거기서는 선형이 압도한다 — 트리는 38.8%의 상태에서 *골드를 벌었는데 승률이 내려간다*.
4. **임의로 정한 값은 2개뿐이다**(`N타`, `SEC`). `ward`/`wardkill`만 데이터로 유도하지 않았는데,
   그것도 **환율 신뢰구간이 자기 값보다 넓다는 측정 결과**에 따른 결정이다.

## 모델 — 2단 구조

```
[행동 7종]  kill · cs · jungle · tower · ward · wardkill · firstBlood
     │   ① 변환기   LinearRegression × 2      "행동 1단위 = 골드/경험 얼마"
     ▼                                        R² 0.948 / 0.851
[goldDiff, expDiff] + [나머지 9피처]
     │   ② 예측기   미러 증강 → 표준화 → LogisticRegression → 계수를 원단위로 역변환
     ▼
P(승) = sigmoid(Σ βf · Δf)
```

### 왜 이 구조인가 — 질문 4개

**① 왜 두 단계로 나눴나**
예측만 할 거면 1단이면 된다. 하지만 게임은 사람이 `kill`을 쳤을 때 **모델 입력이 얼마나 변해야
하는지**를 알아야 한다. 데이터는 "킬 1개 = 승률 +x%"를 직접 말해주지 않는다. 그래서
**"킬 1개 = 골드 +431"** 을 따로 추정했다. 1단계가 없으면 게임이 성립하지 않는다.

**② 왜 1단계가 `LinearRegression`인가**
보상표는 **상태와 무관한 고정 환율**이어야 한다. "지금 상태에서는 킬이 300골드, 저 상태에서는
600골드"면 플레이어가 계획을 세울 수 없다. 선형회귀의 계수는 정의상 고정값이다.
성능으로도 최선이다 (CV R², 전체 9,879경기):

| | LinearRegression (채택) | Ridge(α=1) | Huber | HistGB (비선형) |
|---|---|---|---|---|
| 골드 R² | **0.9476** | 0.9476 | 0.9475 | 0.9441 |
| 고정 환율 | **✅** | ✅ | ✅ | **❌ 상태마다 다름** |

정규화 3종과 소수점 4자리까지 동일하고(피처 7개에 표본 9,879개라 과적합 여지가 없다),
비선형은 성능도 낮으면서 **구조적으로 후보가 아니다.**

**③ 왜 2단계가 `LogisticRegression`인가**
로지스틱은 **로그오즈를 직접 모수화**한다 — `logit = Σ βf·Δf`. 그래서 계수가 곧
"드래곤 1개 = 0.3156 로짓 = 799골드"라는 **환율**이 되고, 게임의 쿨타임·보상·캡·N타 분할이
전부 여기서 유도된다. 트리·신경망은 이 값을 **뽑을 수 없어 게임 설계 자체가 불가능**하다.
AUC로는 LDA·LightGBM과 동률이지만, 아래 증거 요약의 네 지표에서 갈린다.

**④ 왜 따로 학습하나**
두 단계를 이어 붙여 학습하면 1단계의 **추정값**이 2단계의 입력이 되어 오차가 전파된다.
그래서 **둘 다 원본 관측값으로 따로 적합**하고, 추론에서만 연결한다. 얻는 것 둘:

- **학습에 오차 전파가 없다.** (추론에는 있다 — 그 비용은 중앙값 3.9%p로 측정했다)
- **계수가 해석 가능해진다.** 2단계의 `killDiff` 계수는 `goldDiff`를 같은 회귀에 넣고 추정한
  **골드를 통제한 직접효과**다. 골드 경로는 간접효과이고, 게임에서 체감하는 것은
  직접 + 간접 = **총효과** — 이중계산이 아니라 **매개(mediation) 분해**다.

**덤: 미러 증강** — "블루/레드 라벨은 임의"라는 불변성 가정을 데이터에 넣었다(부호·정답 반전
사본 추가). AUC는 그대로인데 **절편이 정확히 0**이 되고 **양쪽 승률 합이 정확히 100%**가 된다.
성능을 올린 게 아니라 **모델이 가져야 할 성질을 유도**한 것이다.

### 증거 요약 — 상세는 [docs/모델검증.md](docs/모델검증.md)

| 지표 | **로지스틱 (채택)** | XGBoost 얕게 | LightGBM 얕게 | RandomForest(500) |
|---|---|---|---|---|
| CV AUC | 0.8109 | 0.8094 | 0.8088 | 0.7995 |
| 쌍체 부트스트랩 (2,000회) | 기준 | 채택 우위 p=.017 | **동률** p=.066 | 채택 우위 p<.001 |
| **단조성** — 골드 벌 때 하락 | **0.0%** | 2.1% | 1.6% | **38.8%** |
| **단조성** — 무반응 | **0.0%** | **68.0%** | **67.7%** | 7.5% |
| **외삽** — 캡 밖 반응 | **+0.48%p** | 0.00%p | 0.00%p | 0.00%p |
| **포화** — +11,000골드 승률 | **99.4%** | 84.8% | 86.9% | **66.8%** |
| **재현성** — 시드 AUC 표준편차 | **0.000000** | 0.000693 | 0.000284 | 0.000771 |
| 1행 추론 | 0.72ms | 0.92ms | 1.78ms | **112.8ms** |
| 모델 크기 | **1.4KB** | 340KB | 284KB | **107MB** |
| **계수 → 게임 환율** | **가능** | 불가 | 불가 | 불가 |
| **게임에 쓸 수 있나** | **✅** | ❌ 68% 무반응 | ❌ 67.7% 무반응 | ❌ 38.8% 역주행 |

**AUC로는 모델이 안 골라진다** — LDA가 0.0003 위이고 LightGBM은 통계적 동률이다.
갈리는 곳은 **단조성과 포화**다. XGBoost·LightGBM은 성능·속도 모두 문제없지만
**68%의 상태에서 명령을 쳐도 게이지가 안 움직이고**(계단함수), RandomForest는
**38.8%에서 거꾸로 간다.** 승률 게이지를 보여주는 게임에서 이건 성능 저하가 아니라 **기능 실패**다.
속도가 결정적인 것은 RandomForest(112.8ms) 하나뿐이다.

> **모델 선택은 AUC 경쟁의 결과가 아니라, 문제에 맞는 평가 기준을 정의한 결과다.**
> 변별력으로는 LDA·LightGBM과 동률이지만 **캘리브레이션·단조성·외삽·재현성·계수 추출**
> 다섯 기준을 통과하는 대안은 없다. 1단계도 같은 논리로 `LinearRegression`이 유일하다.

## 게임 — 상세는 [docs/게임설계.md](docs/게임설계.md)

채팅 명령을 **FIFO 큐**에 쌓고 0.3초에 하나씩 처리한다. **게임 60초 = 실제 10분(압축 10:1)** 이라
쿨타임·스폰이 그대로 환산된다. 명령어 11개가 **데이터 피처 11개와 1:1 대응**한다.

- **쿨타임** = (600초 ÷ 10분 평균 횟수) ÷ 10 — 데이터에서 직접 나온다
- **상한** = 관측 범위(99분위). 임의 조정이 아니라 **모델의 정의역**이다
- **N타 분할** — 앞 N−1타는 자기계수를 선지불(손해), 마지막 타에 보상 일괄 지급
- **오브젝트는 공유 체력 + 막타** — 3/4를 때려도 막타를 놓치면 0을 받는다

| 한계 | 내용 |
|---|---|
| **데이터** | 10분 스냅샷 1장에는 *순서*가 없다. 시계열 데이터가 아니면 AUC 0.81이 천장이다 |
| **접전 구간** | 골드차 ±1,000 구간 AUC 0.598 — 거의 동전던지기 |

| **밸런스** | 완전 균형이 아니다. **속도마다 지배 전략이 존재**하되 1위가 속도에 따라 바뀌고, 상위 4종은 1~5점 차 |

| **`ward`/`wardkill`** | 환율 CI가 자기 값보다 넓어 롤 메커니즘으로 대체했다. 유일하게 데이터 밖 |
